# Tiny Lamp

Tiny Lamp is a USB-C powered lamp with 12 WS2812B LEDs, an ATtiny85, and one rotary encoder. The knob sets hue, saturation, and brightness, and the LEDs sway softly in the chosen color.

See [attiny85/README.md](attiny85/README.md) for controls, wiring, building, and flashing.

The earlier Pico 2 W and ESP32-C3 Wi-Fi versions live on the `tiny-lamp-with-screen` branch.
